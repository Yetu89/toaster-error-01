## The bounty

Write the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer. The line must read like a real message on a real appliance — deadpan, apologetic, quietly dramatic, or plain absurd — and an AI judge compares entries two at a time, picking the funnier, fresher, tighter one.

## The entry

> Your bagel is stuck. I am a toaster, not a locksmith. Please stop shaking me.

77 characters. Grok (grok-4.3) ranked this line the winner at 9/10 (D 7, A 6, C 4): the most authentic stuck-bagel scenario, with a sharp locksmith twist.

## How to run

```sh
node main.ts
```

This writes `/output/entry.txt`. For a local test:

```sh
OUTPUT_DIR=/tmp/out node main.ts
```
